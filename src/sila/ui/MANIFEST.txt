FILES TO COPY INTO YOUR UI FOLDER
=================================

If you prefer manual copy-paste instead of running the zip script,
copy exactly these files (preserving directory structure):

ROOT FILES:
  ✓ index.html
  ✓ package.json
  ✓ tsconfig.json
  ✓ vite.config.ts

src/ (entire directory, including subdirectories):
  ✓ src/App.tsx
  ✓ src/main.tsx
  ✓ src/index.css
  ✓ src/types.ts
  ✓ src/utils/cn.ts
  ✓ src/lib/api.ts
  ✓ src/components/Header.tsx
  ✓ src/components/Omnibar.tsx
  ✓ src/components/MediaGrid.tsx
  ✓ src/components/MediaCard.tsx
  ✓ src/components/SkeletonGrid.tsx
  ✓ src/components/EmptyState.tsx

DO NOT COPY:
  ✗ node_modules/          (regenerated by npm install)
  ✗ dist/                  (regenerated by npm run build)
  ✗ .git/                  (if present)
  ✗ scripts/               (only needed for zipping)

AFTER COPYING:
  1. cd into your UI folder
  2. npm install
  3. npm run dev            (development)
  4. npm run build          (production)
